## Engineering Products

Installable, reusable tools.

**[playwright-order-manager](https://github.com/rajeshyemul/playwright-order-manager)** · [npm](https://www.npmjs.com/package/playwright-order-manager)
Priority-based Playwright execution that improves CI feedback by running the most critical tests first.
*Problem solved:* engineering teams shouldn't wait twenty minutes to discover their first critical failure.
Ordered execution · priority buckets · fail-fast strategy · HTML reporting · CLI · TypeScript API

**[playwright-flaky-tracker](https://github.com/rajeshyemul/playwright-flaky-tracker)**
Detects, classifies, and tracks flaky tests across executions to improve automation reliability.
*Problem solved:* teams need evidence of reliability, not guesswork.

**[playwright-teams-reporter](https://github.com/rajeshyemul/playwright-teams-reporter)**
Delivers Playwright execution summaries directly into Microsoft Teams using Adaptive Cards.
*Problem solved:* engineering feedback should reach people where they already work.

## Engineering Principles

- Quality is a system property - designed in, not inspected in.
- Platform thinking beats project thinking.
- Signal matters more than test count.
- AI should improve engineering decisions, reduce cognitive load, and strengthen engineering capability, not replace engineering judgment.
- Leadership should remove dependency, not create it.
